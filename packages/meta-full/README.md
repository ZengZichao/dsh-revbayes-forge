# RevBayes Forge Full (`dsh-revbayes-forge-full`)

## English

This is a development-only meta package for the RevBayes Forge workspace. It is **not** a DSH bundle and never appears in the DSH plugin list — the core package `dsh-revbayes-forge` already bundles all 13 packs, so installing `packages/core` is the only installation step.

## 中文

这是 RevBayes Forge 工作区的开发用 meta 包。它**不是** DSH bundle，也不会出现在 DSH 插件列表中——core 包 `dsh-revbayes-forge` 已内置全部 13 个模型包，安装 `packages/core` 即可。
